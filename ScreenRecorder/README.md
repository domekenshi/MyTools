# ScreenRecorder

macOS の画面または指定範囲を、システム音声付きMP4として録画する個人用アプリです。

## 必要環境

- macOS 15 以降
- Xcode 26.5 以降

## ビルドと起動

```bash
swift build
swift run ScreenRecorder
```

アプリとして起動する場合は、次のコマンドで `ScreenRecorder.app` を作成できます。

```bash
./build-app.sh
open ScreenRecorder.app
```

初回起動時は、システム設定の「プライバシーとセキュリティ」から画面収録権限を許可してください。
アプリをビルドし直した場合は、画面収録権限の再許可が必要になることがあります。

## 現在の機能

- 「画面＋音声」「音声のみ」のモード切り替え
- 音源の選択（PCの音／マイク／両方）。両方選ぶと1つの音声トラックにミックスされる
- 録画・録音の経過時間表示（mm:ss と秒数）
- 録画するディスプレイの選択
- 移動・拡大縮小できる赤枠による録画範囲の指定
- ディスプレイごとの録画範囲の保存（ディスプレイ固有のUUIDで覚えるので、抜き差しや再起動で入れ替わらない）
- 赤枠内の範囲録画（赤枠自体は動画から除外）
- MP4 保存（音声のみモードは M4A / AAC 48kHz ステレオ）
- 保存先の変更（モードごとに保存先を記憶）
- 録画開始・停止
- システム音声の録音

音声のみモードは映像を保存せず、選んだ音源だけを M4A に書き出します。
内部ではいったん最小サイズの動画として録り、停止時に音声トラックだけを取り出しています。
通常は再エンコードなしのパススルーで、それができない構成のときだけ AAC で焼き直します。

macOS の仕様上、音声のみモードでも画面収録の権限が必要です。
マイクを使うときは、初回にマイクの使用許可を求められます。

ショートカット、マイクの入力デバイス選択、音量バランスの調整は次の拡張候補です。

## 動作確認（スモークテスト）

GUI セッション経由で起動すると 3 秒だけ録画・録音してファイルを書き出します。

```bash
open -n -a /Applications/ScreenRecorder.app --args --smoke-test-audio ~/Desktop/test.m4a
open -n -a /Applications/ScreenRecorder.app --args --smoke-test ~/Desktop/test.mp4
```

保存先の直後に `--mic`（マイクを足す）、`--no-system-audio`（PCの音を外す）、
`--display N`（N番目の画面を対象にする）を渡せます。フラグは必ず保存先より後ろに置きます。
失敗したときは保存先の隣に `.log` を書き出します。

画面収録の権限はターミナルから直接起動したプロセスには下りないので、
`open -n -a` でアプリとして起動してください。
