# ScreenRecorder

macOS の画面または指定範囲を、システム音声付きMP4として録画する個人用アプリです。

## 必要環境

- macOS 15 以降
- Xcode 26.5 以降

## ビルドと起動

```bash
swift build
swift run ScreenRecorder
```

アプリとして起動する場合は、次のコマンドで `ScreenRecorder.app` を作成できます。

```bash
./build-app.sh
open ScreenRecorder.app
```

初回起動時は、システム設定の「プライバシーとセキュリティ」から画面収録権限を許可してください。
アプリをビルドし直した場合は、画面収録権限の再許可が必要になることがあります。

## 現在の機能

- 録画するディスプレイの選択
- 移動・拡大縮小できる赤枠による録画範囲の指定
- ディスプレイごとの録画範囲の保存
- 赤枠内の範囲録画（赤枠自体は動画から除外）
- MP4 保存
- 保存先の変更
- 録画開始・停止
- システム音声の録音

ショートカット、マイク音声、音声のミックス調整は次の拡張候補です。
