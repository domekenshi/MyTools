# 集中ループタイマー

集中時間と5分休憩を、停止するまで自動で繰り返す軽量なmacOSメニューバーアプリです。
Webブラウザや外部通信は使いません。

## 機能

- 集中時間：15分、30分、45分、60分、75分、150分、または1〜180分のカスタム
- 休憩時間：1分・3分・5分・10分・15分のワンタップ設定、または1〜60分で調整（初期値5分）
- 集中と休憩の自動ループ
- 5秒・10秒・15秒・20秒から選べる、自動停止するアラーム
- 集中・休憩・アラームを同じ配置のワンタップボタンで設定
- メニューバー表示と、自由に移動できる独立ウインドウ表示の切り替え。選択は保存され、次回起動時にも適用
- 独立ウインドウは自由にリサイズでき、タイマー実行中は250px幅まで円形表示も追従。設定中は元の340px幅を下限にして全項目を読みやすく表示
- タイマー実行画面は「最小」「小」「中」でウインドウ全体を一括変更でき、開始時は「小」を適用
- 選択中の設定を緑の塗りつぶしとチェックマークで明示
- カスタム時間は数字の直接入力と増減ボタンの両方に対応
- 完了セット数とメニューバーの残り時間表示
- タイマー実行中のアイドルスリープ抑止

## ビルドと起動

```bash
./build-app.sh
open FocusLoop.app
```

起動するとDockではなくメニューバーに表示されます。終了するときは画面下部の「終了」を押します。
Finderから使いやすくする場合は、作成された `FocusLoop.app` を「アプリケーション」フォルダへ移動してください。
